# Signal Reference

This document defines all signal types generated by the Robinhood Chain Opportunity Intelligence Dashboard.

## Signal Object Standard

Every signal returns:

```json
{
  "id": "sig_...",
  "type": "SMART_ACCUMULATION",
  "entityType": "TOKEN",
  "entityId": "0x...",
  "rawScore": 87,
  "riskScore": 28,
  "adjustedScore": 67,
  "confidence": "HIGH",
  "dataCompleteness": 0.92,
  "window": "6h",
  "evidence": [],
  "riskFlags": [],
  "invalidators": [],
  "createdAt": "..."
}
```

---

## SMART_ACCUMULATION

**Purpose**: Detect organic accumulation by smart money wallets with growing holder base.

### Conditions (5 factors)

| Factor | Metric | Threshold | Description |
|--------|--------|-----------|-------------|
| 1 | `smart_money_net_flow_6h` | > 0 | Positive net flow from smart wallets |
| 2 | `holder_growth_24h` | > 0 | Holders increasing |
| 3 | `unique_buyer_growth_6h` | > 0 | Unique buyers increasing |
| 4 | `liquidity_change_6h` | ≥ 0 | Liquidity stable or growing |
| 5 | `top10_concentration_change` | ≤ 0.05 | Concentration not spiking |

### Scoring
- **Raw Score**: `(conditions_met / 5) × 100`
- **Confidence**: HIGH if ≥ 4 conditions, MEDIUM if ≥ 3
- **Minimum**: 3 conditions required to generate signal

### Evidence
Each satisfied condition contributes to the evidence array with metric name, value, and threshold.

### Invalidation
Each unsatisfied condition is added to the invalidators list.

## CAPITAL_ROTATION

**Purpose**: Detect capital entering via bridge and flowing into specific tokens/protocols.

### Conditions (4 factors)

| Factor | Metric | Threshold | Description |
|--------|--------|-----------|-------------|
| 1 | `bridge_net_inflow_1h` | > 0 | Positive bridge inflow |
| 2 | `destination_token_net_buy_1h` | > 0 | Net buying in destination token |
| 3 | `dex_liquidity_change_1h` | > 0 | DEX liquidity increasing |
| 4 | `wallet_diversification` | > 0.5 | Multiple wallets participating |

### Scoring
- **Raw Score**: `(conditions_met / 4) × 100`
- **Confidence**: HIGH if 4/4, MEDIUM if 3/4
- **Minimum**: 3 conditions required

## NEW_TOKEN_BREAKOUT

**Purpose**: Identify new tokens showing genuine adoption, not bot/airdrop activity.

### Conditions

| Factor | Metric | Threshold | Description |
|--------|--------|-----------|-------------|
| 1 | Token age | > 24h | Anti-sniping minimum age |
| 2 | Liquidity | ≥ $5,000 | Minimum viable liquidity |
| 3 | Unique buyers | ≥ 10 | Genuine demand |
| 4 | Sell transactions | > 0 | At least one real sell |
| 5 | Top 10 share | < 0.3 | Not highly concentrated |
| 6 | Smart money flow | ≥ 0 | Positive (preferred) |

### Scoring
- **Raw Score**: Based on conditions met, weighted by liquidity depth and buyer diversity
- **Confidence**: HIGH if ≥ 5 conditions including smart money, MEDIUM if ≥ 4

### Risk Gates
- If age < 24h: signal blocked (anti-sniping)
- If top 10 share > 0.5: signal invalidated

## STOCK_TOKEN_DIVERGENCE

**Purpose**: Detect exploitable price divergence between DEX and reference price for canonical Stock Tokens.

### Conditions (5 factors)

| Factor | Metric | Threshold | Description |
|--------|--------|-----------|-------------|
| 1 | Canonical | true | Must be official Robinhood Stock Token |
| 2 | Reference price fresh | < 60 min | Price data not stale |
| 3 | Trading not halted | false | Underlier actively trading |
| 4 | Premium/discount | > 1% | Meaningful divergence |
| 5 | Executable depth | ≥ $5,000 | Enough liquidity to trade |

### Scoring
- **Raw Score**: `(conditions_met / 5) × 100`
- **Confidence**: HIGH if 5/5, MEDIUM if 4/5
- **Minimum**: 4 conditions required

### Critical Invalidation
- Non-canonical tokens are immediately excluded
- Stale reference price (multiplier changed) invalidates signal
- Corporate action mismatch is an invalidator

## FAKE_MOMENTUM_WARNING

**Purpose**: Flag tokens showing artificial momentum patterns (bot activity, sybil, wash trading).

### Trigger Conditions (any 2+)

| Condition | Metric | Threshold | Description |
|-----------|--------|-----------|-------------|
| 1 | `transfers_per_holder` | > 100 | Extreme transfer ratio |
| 2 | `sybil_ratio` | > 0.3 | High sybil/bot proportion |
| 3 | `holder_growth_without_active` | true | Holders growing but no active trading |
| 4 | `price_liquidity_divergence` | > 0.2 | Price rising while liquidity falling |
| 5 | `creator_wallet_dominance` | true | Creator-related wallets dominate volume |

### Risk Flags Generated
- `EXTREME_TRANSFER_RATIO`
- `HIGH_SYBIL_RATIO`
- `HOLDER_ANOMALY`
- `PRICE_LIQUIDITY_DIVERGENCE`
- `CREATOR_DOMINANCE`

### Impact
This signal generates `risk_flags` that are attached to the token's Risk Score. It does NOT generate an opportunity score.

## TICKER_COLLISION

**Purpose**: Alert when a non-canonical token uses a stock-like ticker or name.

### Detection
- Token has stock-like symbol (e.g., GME, NVDA, AAPL)
- Token contract address is NOT in Robinhood's official `/rhj/assets` registry

### Result
- **Risk Flag**: `TICKER_COLLISION`
- **Hard Gate**: GATE-01 triggered
- **Status**: `RESTRICTED`
- **Stock Token Radar**: Excluded from canonical listing

---

## LIQUIDITY_REMOVAL

**Purpose**: Detect significant LP position withdrawals that may signal impending price impact.

### Conditions
- LP removed > 20% of pool liquidity in 1h
- Or LP removed > 50% of their position

### Impact
- Generates risk alert
- Triggers `LIQUIDITY_REMOVAL` risk flag

---

## CONTRACT_RISK_CHANGE

**Purpose**: Detect changes in contract permissions or implementation that alter risk profile.

### Triggers
- Proxy implementation changed
- New privileged methods detected (mint, blacklist, pause)
- Ownership transferred

### Impact
- Updates risk score components
- May trigger hard gates if severe

---

## Signal Lifecycle

1. **Generated**: Signal created with initial score
2. **Active**: Signal is current and actionable
3. **Expired**: Time window passed without refresh
4. **Invalidated**: Invalidation condition met (e.g., liquidity drained, halted)
